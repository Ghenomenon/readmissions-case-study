# 30-Day Readmissions: Healthcare Analytics Case Study

Complete project by Chigozie Nkwopara.

## Download the project

[Download the full project source](readmissions-case-study-source.zip). Extract the ZIP into a folder named `readmissions-case-study`. The archive contains the complete source, documentation and original folder structure.

Read `README.md` inside the extracted folder for setup and use.

Python analysis, aggregate tables, figures and the final report for a reproducible study of 30-day diabetes readmissions.

Patient-level data is excluded. Download the original UCI dataset and follow the included setup instructions.
